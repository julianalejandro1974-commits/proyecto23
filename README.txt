CLIMAAHORA - Proyecto académico con Visual Crossing Weather

ARCHIVOS
- index.html: estructura de la aplicación.
- styles.css: estilos y diseño adaptable a celulares.
- script.js: consulta a la API y actualización de la interfaz.

CÓMO EJECUTAR
1. Descomprime el ZIP.
2. Abre la carpeta del proyecto.
3. Abre index.html en el navegador.
4. Escribe una ciudad y pulsa Consultar.
5. Usa el botón ↻ para actualizar el pronóstico.

NOTAS
- El proyecto utiliza únicamente HTML, CSS y JavaScript.
- La aplicación consulta Visual Crossing Timeline API.
- Muestra condiciones actuales, viento, probabilidad de lluvia, humedad y datos horarios del periodo de 24 horas anteriores y posteriores.
- La API Key está escrita en script.js para facilitar la entrega académica. No publiques el proyecto en un repositorio público con una clave real.
- Si el navegador bloquea la petición al abrir el archivo directamente, ejecuta la carpeta con Live Server (extensión de VS Code).
